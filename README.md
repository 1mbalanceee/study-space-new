# Study Space · Самарский Университет (SSAU)

Современное PWA-приложение для студентов Самарского национального исследовательского университета имени академика С.П. Королёва (группа 6131-010402D).

## Возможности
- 📅 **Расписание 2026/2027 уч. года**: предустановлены все пары, преподаватели, кабинеты и звонки Самарского университета.
- 🔄 **Двухсторонняя синхронизация с Firebase Firestore**: доступ к данным с телефона, планшета и ПК.
- 🛡️ **Офлайн-режим (PWA & Service Worker)**: работает автономно без интернета, данные кэшируются в IndexedDB.
- 📝 **Заметки, домашние задания и прикрепление файлов**: файлы хранятся локально в браузере.
- 📊 **Трекер посещаемости и рефлексии**: учет посещенных пар и ежедневный отчет продуктивности.
- 🔒 **Безопасность**: защита от XSS, экранирование входных данных, изоляция пользовательских данных.

## Стек технологий
- HTML5, Vanilla JavaScript, CSS3
- Firebase Authentication & Cloud Firestore (offline persistence)
- Service Worker (Cache Storage) & IndexedDB
- Web App Manifest (PWA)

## Развертывание (Vercel / GitHub Pages)
Приложение полностью статическое и готово к деплою на Vercel, Netlify или GitHub Pages.
Не забудьте добавить домен вашего сайта в **Firebase Console -> Authentication -> Settings -> Authorized domains**.
