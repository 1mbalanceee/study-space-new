# Study Space · Самарский Университет (SSAU)

Современное PWA-приложение для студентов Самарского национального исследовательского университета имени академика С.П. Королёва (группа 6131-010402D).

## Возможности
- 📅 **Расписание 2026/2027 уч. года**: предустановлены все пары, преподаватели, кабинеты и звонки Самарского университета.
- 📚 **Отдельная страница предметов**: удобный каталог всех дисциплин, преподавателей, аудиторий, ссылок и статистики посещаемости.
- ✅ **Трекер домашних заданий и дедлайнов**: интерактивное выполнение ДЗ прямо на странице предметов и во вкладке «Сегодня».
- ⚡ **Отслеживание подготовки к следующей паре**: интеллектуальный расчет даты и времени следующего занятия по предмету с быстрыми пресетами дедлайнов.
- 🗑️ **Безопасное управление расписанием**: разовое удаление пары на конкретную дату без изменения базового расписания (с подтверждением), защита от случайного удаления в редакторе.
- 🔗 **Примечания к ссылкам**: структурированное хранение ссылок с описанием (Zoom, Google Диск, СДО SSAU, чат группы, конспекты) и быстрыми тегами.
- 🔄 **Двухсторонняя синхронизация с Firebase Firestore**: доступ к данным с телефона, планшета и ПК.
- 💾 **Надежное сохранение стейтов**: автосохранение активной вкладки, выбранной недели, локальные снапшоты версий и резервный экспорт/импорт.
- 🛡️ **Офлайн-режим (PWA & Service Worker v5)**: работает автономно без интернета, данные кэшируются в IndexedDB и LocalStorage.
- 📊 **Трекер посещаемости и ежедневной рефлексии**: учет посещенных пар и отчет продуктивности.
- 🔒 **Безопасность**: защита от XSS, экранирование входных данных, изоляция пользовательских данных.

## Стек технологий
- HTML5, Vanilla JavaScript, CSS3
- Firebase Authentication & Cloud Firestore (offline persistence)
- Service Worker (Cache Storage) & IndexedDB
- Web App Manifest (PWA)

## Развертывание (Vercel / GitHub Pages)
Приложение полностью статическое и готово к деплою на Vercel, Netlify или GitHub Pages.
Не забудьте добавить домен вашего сайта в **Firebase Console -> Authentication -> Settings -> Authorized domains**.
